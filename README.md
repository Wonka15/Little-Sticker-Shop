# Little Sticker Drops

A mobile-friendly, static limited-edition sticker storefront for GitHub Pages.

## Sample product
Retro Computer Club — $4.00 example price, 25-copy edition. Demo only: no live inventory or eBay listing.

## Enable GitHub Pages
Go to **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.

Expected site URL once enabled: https://wonka15.github.io/Little-Sticker-Shop/

## Connect eBay
After creating an eBay listing, replace the disabled purchase element in `index.html` with a link to your verified eBay listing. Manage stock, shipping, and returns on eBay. This static website does not synchronize quantities.

## Security
No payment processing, accounts, database, or secrets. Never commit customer data or API credentials. Enable GitHub two-factor authentication.
