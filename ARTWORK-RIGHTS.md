# © Otter Stickers — Artwork Rights & Safe Publishing

## Beginner guide
Original artwork remains the property of its respective copyright owner. Browsing or purchasing a physical sticker does not grant permission to copy, redistribute, modify, print, or resell the artwork, except where permission is explicitly given.

**Suggested public notice:** “© Otter Stickers. Original artwork and illustrations. All rights reserved. Please do not reproduce or resell designs without written permission.”

## Before publishing
1. Keep layered source files, print masters, client work, and customer information in **private** storage, not this public repository.
2. Export a smaller web preview (roughly 1200 × 1200 px, ideally under 500 KiB when practical).
3. Remove unnecessary embedded metadata from public previews.
4. Upload only preview files into `images/` and reference them in `products.json`.
5. Keep dated originals and design records as evidence of authorship.

A copyright notice **does not stop** downloads, screenshots, scraping, or GitHub forks. Watermarks can discourage some reuse but are not technical protection. For legal enforcement or licensing decisions, consult a qualified professional.

## Repository licensing
A software license and an artwork license are different. Do not assume that an open-source code license automatically grants reuse rights to original artwork. Clearly document each if you add a repository license.
