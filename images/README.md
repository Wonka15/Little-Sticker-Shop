# Curbside Stickers — Image Jar\n\nUpload your web-optimized sticker images into this folder. Use WebP when practical, ideally 1200 × 1200 pixels and 500 KB or less per image. Add the matching path to products.json (example: images/robot.webp).\n\nUse the Image Jar at ../image-jar.html to measure published catalog images and check new files locally. This is a suggested loading-performance budget, not a GitHub storage quota. Keep print-quality originals elsewhere.\n
